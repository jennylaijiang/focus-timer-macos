# Focus v1.0

A small, offline macOS timer with a space to capture thoughts and ideas to return to later.

- Start a named task with a custom duration.
- Pause, resume, and continue into overtime.
- Capture thoughts while focusing and copy them when needed.
- Review completed sessions and thoughts in local history.
- Keep the window on top or collapse the thought sidebar.

Requires **macOS 14 or later**. The universal release supports **Apple Silicon and Intel Macs**. Sessions and thoughts stay on your Mac. No accounts or internet connection required.

**First launch:** This release is not notarized by Apple, so macOS may block its initial launch. If you trust the source (that’s me!), follow [Apple’s instructions for opening the app](https://support.apple.com/en-gb/102445).

See the [README](https://github.com/jennylaijiang/focus-timer-macos#closing-sleep-and-recovery) for details about saving, sleep, and session recovery.
